# 容器构建的字体下载

2026-10-19 服务器构建日志中，`fonts-noto-cjk` 安装步骤超过 1061 秒，停在从 `deb.debian.org` 下载约 56.5 MB 的字体包；同期 `npm ci` 约 56 秒、Next.js 构建约 65 秒。主要等待发生在系统字体安装阶段。

Dockerfile 的 Debian 主仓库已改为腾讯云镜像，兼容 Debian 12 的 DEB822 配置和传统 sources.list。已核对 bookworm、bookworm-updates 索引和对应字体包可访问。参考[腾讯云 Debian 镜像说明](https://mirrors.cloud.tencent.com/help/debian.html)。安全更新默认保留官方 `security.debian.org`；需要其他镜像时可通过 `DEBIAN_MIRROR`、`DEBIAN_SECURITY_MIRROR` 构建参数指定。

APT 网络连接及读取超时为 20 秒，失败最多重试 2 次，整个更新和字体安装阶段最多运行 300 秒，超时退出；退出时最多再给子进程 10 秒清理。下载持续低速时也有总时间上限。没有安装字体的镜像不会继续构建成功，避免中文报表缺字。

Node slim 基础镜像可能缺少系统 CA 文件。安装期间临时使用基础镜像中 Node 内置的公共根证书验证 HTTPS；安装后删除临时配置。APT 原有的 Debian 签名校验继续保留，不禁用 TLS 校验或仓库签名校验。

已经成功备份且暂未切换容器时，中止卡住的构建后，不必重复生成整库备份。推送并拉取这次 Dockerfile 更新，再执行：

```bash
sudo docker compose --progress plain build web &&
sudo docker compose up -d --force-recreate --wait --wait-timeout 180 web worker &&
curl --max-time 10 -fsS http://127.0.0.1:3108/api/health &&
sudo docker compose ps
```

`--progress plain` 输出完整构建日志，便于区分下载、编译和镜像导出。不要使用 `--no-cache` 或再次清理缓存来重试，避免重复下载已完成的依赖。更换 Dockerfile 不修改宿主机的软件源和服务器已有环境配置。
