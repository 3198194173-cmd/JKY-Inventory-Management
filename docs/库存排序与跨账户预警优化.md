# 库存排序、跨账户预警去重与手机布局

2026-10-15 用户确认：同一仓库、同一接收群、相同商品与业务数据只发送一次；不同接收群分别发送。

- 销售均值和库存周转均支持升降序。桌面点击表头切换，手机在顶部统一排序菜单选择指标或某日销量。按整个筛选结果计算后分页；均值比较未舍入7天总销量，周转通过精确交叉乘法比较，未知值始终置尾，负值正常排序，同值按商品编码稳定排列。
- 共享预警账本按钉钉应用、机器人、群、仓库及业务内容指纹原子占位，手动和自动通知共同使用。指纹包含业务日期、商品、单位、库存、销量、在途和补货；忽略账户、快照ID、采集时刻、仓库别名、筛选规则文字和临时导出链接。账户配置、业务数据和报告下载授权仍独立。
- 完整受理、部分受理、网络中断或结果未确认均不自动重投同一份内容；只有明确拒绝且未受理任何部分才允许另一次发送。新业务日期或变化的数据可以生成新报告，既有的每仓每日自动通知限制继续生效。相同内容即使过了手动冷却时间也不重复发送。
- 本次新增共享账本从新版实际发送开始记录，不读取或回溯钉钉群中的历史消息。数据库迁移为 `0019_shared_alert_deliveries.sql`，web 和 worker 需一起升级。
- 手机工具栏收为三行：仓库、搜索及两个操作按钮、排序与日期范围。完整操作名保留无障碍标签。更新时间简写，概览缩小，采集核验详情默认收起，删除重复的每日销量排序区。错误、进行中的采集及缺失库存提示继续直接显示；指标说明可展开。

手机导航保留库存、在途、记录、预警四个主要入口，采集时间设置从状态栏进入；桌面原设置入口保留。生产构建、全仓指标排序和并发跨账户去重测试已通过；本地浏览器检查覆盖320、390、760像素布局和桌面表头升降序，尚未部署云端，测试未发送真实预警。
